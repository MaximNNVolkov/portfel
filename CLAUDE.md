# Портфель — точка входа в документацию

Все документы проекта лежат в `docs/`. Этот файл существует только потому, что
Claude Code автоматически подхватывает `CLAUDE.md` из корня репозитория, а не из
подкаталога — без него правила разработки в новой сессии не загрузятся.

Правила разработки: @docs/CLAUDE.md
Техническое задание: @docs/SPEC.md

- `docs/.NEXT_STEPS.md` — план работ по этапам 0-6.
- `docs/RELEASE_PLAN.md` — план вывода в прод для внутреннего тестирования.
- `docs/TEST_FEEDBACK.md` — отчёт о внутреннем тестировании стенда.
- `docs/FIX_PLAN.md` — очередь правок по итогам тестирования.
- `docs/CLIENT_FLOW_PLAN.md` — редизайн содержания экранов по сценарию клиента (волны A-F выполнены).
- `docs/DEPLOY.md` — процедура деплоя на VPS.
- `docs/mockups.html` — интерактивные макеты ключевых экранов.
