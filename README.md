# Капитал

Веб-приложение для учёта и анализа инвестиционного портфеля.

Сейчас реализован первый экран MVP:

- сводка стоимости портфеля и P&L;
- график динамики стоимости;
- распределение по классам активов;
- ближайшие выплаты;
- адаптивная навигация и демонстрационные интерактивные состояния.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

Данные на стартовом экране демонстрационные. Следующий этап MVP — модели портфеля, ручное добавление инструментов и REST API.
