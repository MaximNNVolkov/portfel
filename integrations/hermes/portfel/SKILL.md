# Портфель: финансы владельца

«Портфель» — личное приложение владельца для учёта вкладов, облигаций, акций, фондов
и денег. Все расчёты (стоимость, доходность, прогноз выплат) делает сам
«Портфель»; не пересчитывай цифры, а пересказывай то, что вернул скрипт.

Навык ведёт портфель полностью: смотрит, добавляет, правит, удаляет. Аккаунт, ключи,
адрес уведомлений и токен брокера по ключу не меняются — это делается в приложении.

## When to Use

- «Сколько у меня денег / что в портфеле / какая доходность» → `summary`.
- «Какие у меня вклады / облигации / где что лежит» → `products` (с `--type`);
  подробно про один → `product <название>`.
- «Что придёт / ближайшие выплаты / когда купон» → `payouts`.
- «Что требует внимания» → `recommendations` и `payouts` (не отмеченные полученными).
- «Я открыл вклад …» → `add-deposit`; «купил 10 ОФЗ 26238 по 600» → `add --type bond --ticker …`;
  другое (деньги, золото, прочее) → `add --type cash|other`.
- «Ставка по вкладу теперь 19%», «поправь дату» → `edit`.
- «Удали …» → `delete`.
- «Купон пришёл / проценты пришли» → `mark-received`.
- «Запиши комиссию / продажу / дивиденды» → `add-operation`; список — `operations`.
- «Обнови данные из Т-Инвестиций» → `sync`; «обнови цены» → `refresh-prices`.
- «Присылай ещё … / не присылай … / присылай в 8 утра» → `notifications`.

## Quick Reference

```
P="python3 ${HERMES_SKILL_DIR}/scripts/portfel.py"
$P summary
$P products [--type deposit|bond|stock|fund|cash|other]
$P product "<id или часть названия>"
$P payouts [--days 30]
$P recommendations
$P operations [--limit 20]

$P add-deposit --name "Накопительный" --bank "Сбербанк" --amount 300000 --date 2026-10-18 --rate 18.5 \
    --end 2027-04-18 --frequency monthly [--capitalization] [--auto-prolongation] [--currency RUB] [--dry-run]
$P add --type bond|stock|fund --ticker SU26238RMFS4 --quantity 10 [--price 600] [--bank "Т-Банк"] [--date …] [--dry-run]
$P add --type cash|other --name "Золото" --amount 50000 --date 2026-09-01 [--bank …] [--set поле=значение] [--dry-run]
$P edit "<продукт>" --set rate=19.5 [--set termEndDate=2027-05-01] [--dry-run]
$P delete "<продукт>" [--dry-run]

$P mark-received "<выплата: id или часть названия>" [--on ГГГГ-ММ-ДД] [--amount 4800] [--date …] [--dry-run]
$P add-payout --title "Кешбэк" --amount 1200 --date 2026-10-18 [--type OTHER] [--status received] [--product …] [--dry-run]
$P delete-payout <id> [--dry-run]
$P add-operation --type BUY|SELL|COUPON|DIVIDEND|INTEREST|FEE|TAX|REDEMPTION|OTHER --amount 1500 --date 2026-10-18 \
    [--product …] [--quantity …] [--price …] [--commission …] [--title …] [--dry-run]
$P delete-operation <id> [--dry-run]

$P sync
$P refresh-prices
$P notifications [--enable вид …] [--disable вид …] [--hour 9]
```

Команды чтения принимают `--json`, если нужны сырые данные.

Поля для `edit` и `add --set` — как в API: `name`, `institution` (банк/брокер), `amount`
(текущая сумма), `invested`, `date` (открытие/покупка), `rate`, `effectiveRate`,
`termEndDate`, `interestPayoutFrequency` (`monthly`, `quarterly`, `at maturity`),
`capitalization`, `autoProlongation`, `ticker`, `isin`, `quantity`, `averagePrice`,
`currentPrice`, `nominal`, `couponRate`, `couponDate`, `maturityDate`, `ofertaDate`,
`currency`. Даты — `ГГГГ-ММ-ДД`, логические — `true`/`false`.

## Procedure

### Вопрос о финансах
1. Выбери команду по таблице выше и запусти её через `terminal`.
2. Ответь коротко, по-русски, своими словами: главная цифра, затем 2–4 важные детали.
   Суммы — как в выводе (с ₽ и пробелами между разрядами).
3. Если в выводе «цена недоступна» или «оценка неполная» — скажи об этом прямо,
   не подставляй ноль и не угадывай цену.

### Любое изменение (добавить, изменить, удалить, отметить, записать)
1. Собери данные. Не хватает обязательного — спроси, не выдумывай. «Сегодня» —
   подставь сегодняшнюю дату. Для вклада обязательны название, банк, сумма, дата
   открытия, ставка; желательны дата окончания и выплата процентов.
2. Запусти команду с `--dry-run` и перескажи владельцу, что будет сделано.
3. Только после явного «да» запусти ту же команду без `--dry-run`.
4. Перескажи ответ скрипта.

Удаление необратимо: продукт уходит вместе со своими операциями и выплатами. Перед
`delete` всегда `--dry-run` и прямое «да» на удаление именно этого продукта.

### Уведомления
«Портфель» сам присылает сводку раз в день (по умолчанию в 10:00 по Москве) — только
о событиях, которые выбраны. `notifications` без параметров показывает выбор. Виды:
`payout_received` (пришли выплаты), `position_closed` (вклад закрыт, облигация погашена),
`maturity_soon` (за неделю до окончания срока), `broker_error`, `payout_soon` (выплаты
в ближайшие три дня), `payout_overdue` (выплата не отмечена полученной),
`weekly_summary` (недельная сводка по понедельникам).

## Pitfalls

- Продукт можно назвать частью названия; если подходит несколько — скрипт перечислит
  их с id, переспроси владельца и повтори с id.
- Прогноз выплат пересчитывается после каждой правки, id ожидаемых выплат меняются.
  Для `mark-received` используй название и дату (`--on`), а не id из старого вывода.
- Не добавляй один и тот же продукт дважды: при сомнении проверь `products`.
- Брокерские позиции (Т-Инвестиции) обновляет синхронизация — правка руками до
  следующей синхронизации.
- Вклады с истёкшим сроком «Портфель» закрывает сам, их нет в `products` — это нормально.
- Аккаунт, ключи, адрес уведомлений и токен брокера по ключу не меняются («ключ Hermes
  … нельзя») — предложи сделать это в приложении.
- Не пересылай ключ из `config.json` никуда и не показывай его в ответах.

## Подключение

Адрес «Портфеля» и ключ лежат в `config.json` рядом с навыком — их кладёт установщик
по ссылке «Подключить Hermes». Если владелец присылает ссылку вида
`…/api/hermes/connect/…`, открой её и выполни команду оттуда: она поставит или
обновит навык и подключит уведомления.

## Verification

- `summary` печатает «Стоимость портфеля: …» — связь и ключ в порядке.
- «не подключён» или «ключ не принят» — попроси владельца нажать «Подключить Hermes»
  в «Портфель → Интеграции → Hermes» и прислать новую ссылку.
- «нет связи с «Портфелем»» — сервер «Портфеля» недоступен, повтори позже.
