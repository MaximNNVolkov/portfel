## BUG-01 (blocker) — backend не поднимается сам, стенд отдаёт 502

```
Что делал:      Открыл https://portfel.176.109.108.58.nip.io/, нажал «Создать новый аккаунт»,
                заполнил email/пароль/код приглашения, нажал регистрацию.
Что ожидал:     Аккаунт создаётся, попадаю в приложение.
Что произошло:  POST /api/auth/register → 502 Bad Gateway. Весь API недоступен,
                приложение выглядит «сломанным» без объяснения причины.
                Причина: процесс backend (npm run api, порт 3001) не запущен, и на сервере
                нет никакого supervisor'а — ни systemd-юнита (`/etc/systemd/system` пуст по
                portfel), ни pm2 (`which pm2` → нет), ни docker-контейнера для portfel.
                nginx (/etc/nginx/sites-available/portfel) проксирует /api/ на 127.0.0.1:3001,
                но поднимать 3001 некому. После любой перезагрузки VPS или падения процесса
                стенд ложится до ручного `npm run api`.
                Повторилось дважды за два прогона тестирования.
Браузер:        Chrome (headless, Linux) — не зависит от браузера, отказ серверный.
Скриншот:       —  (воспроизводится curl'ом: curl -i .../api/health → 502)
```
Как чинил вручную: `cd /home/user1/portfel && npm run api` + `npm run scheduler`.
Предложение: добавить systemd-юниты portfel-api.service и portfel-scheduler.service
с `Restart=always` и `WantedBy=multi-user.target` (см. docs/DEPLOY.md).
