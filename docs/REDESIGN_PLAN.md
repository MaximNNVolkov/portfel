# Редизайн: единый стиль списков во всех вкладках (по образцу «Инструментов»)

## Цель

Вкладка «Инструменты» переработана в компактный двухстрочный список (вариант B,
см. `sketches/002-product-row/`). Владелец доволен и просит привести остальные
вкладки к тому же визуальному языку. Это задача на несколько ночей — выполняй
строго по порядку, по одной вкладке за заход, один осмысленный коммит на вкладку.

## Эталон (что уже сделано и что повторяем)

Классы и поведение — в `src/AppMvp.tsx`, страница `ProductsPage` (раздел с
`.product-list`, `.product-row-summary`, `.product-row-line1/line2`,
`.product-row-name`, `.product-row-sum`, `.product-row-meta`,
`.product-row-meta-amount`, `.list-row-details`, `.detail-line`), стили в
`src/App.css`. Ключевые черты, которые переносим на другие списки:

1. Один общий блок `.product-list` с тонкими разделителями между строками, а не
   отдельная рамка у каждой карточки.
2. Двухстрочная строка: сверху название (слева) + сумма (справа, bold); снизу
   мелким приглушённым (`.muted`) — короткая мета-строка слева + прирост/дата
   справа.
3. Цветная точка типа слева (`.legend.type-dot` + палитра `typeColors`).
4. Раскрытие по тапу на месте (`.list-row-details` + `.detail-line`), кнопка
   «Подробнее →» там, где у вкладки есть страница детализации.
5. Единый безопасный формат дат: `parseIsoDate` + `dateLabel` («1 окт» / «1 ноя
   2025»), никакого «Invalid Date».
6. Панель действий (`.toolbar`): на мобильном кнопки короткие без переноса
   (`label-short`), фильтр/сортировка отдельным рядом `.filters-bar` в два столбца
   (`1fr 1fr`) — см. уже исправленный мобильный CSS в конце `src/App.css`.
7. `env(safe-area-inset-bottom)` в нижнем отступе списка, `overflow-x: hidden` на
   body — горизонтальной прокрутки быть не должно на 390 px.

## Порядок работ (одна вкладка = один заход)

Признак готовности вкладки: строки выглядят как на «Инструментах», всё помещается
на ширине 390 px без горизонтальной прокрутки, `npx tsc -b` и `npm run build`
чистые, скриншот снят и вклеен в отчёт.

### Волна 1 — «Операции» (`TransactionsPage`, ~строка 2297)
Сейчас `.list-card` + `.list-row` с бейджем типа. Переведи на `.product-list` +
двухстрочную строку: название операции слева + сумма справа; ниже мелко — тип
операции (мета) слева + дата справа. Цветная точка по типу операции (сопоставь
разумно: покупка/пополнение/выплата — свои цвета, добавь словарь
`transactionTypeColors`). Раскрытие оставь: инструмент, дата, валюта (уже есть
`.detail-line`). Кнопку «＋ Новая операция» сделай короткой на мобильном
(`label-short`).

### Волна 2 — «Выплаты» (`PaymentsPage`, ~строка 2454)
Там группы по дате (day/month) и просроченные. Сохрани группировку и «отметить
полученной». Каждую строку выплаты переведи на двухстрочный компакт: сверху тип
выплаты (название инструмента/описание) + сумма; снизу мелко — дата + (для
просроченных) пометка. Цветная точка по типу выплаты (словарь `payoutTypeColors`
по `payoutTypeLabels`). Кнопки «Отметить все полученными» и фильтры — короткие на
мобильном.

### Волна 3 — «Аналитика» (`AnalyticsPage`, ~строка 3121) и «Рекомендации» (~3229)
«Аналитика» — карточки/разбивки. Приведи карточки к общему виду: скругление,
отступы, заголовок + сумма + приглушённая мета-строка, палитра точек типов.
«Рекомендации» — статьи `.recommendation`. Выровняй их под общий стиль (радиус,
фон, отступы, иконка-точка слева), не меняя логику загрузки.

### Волна 4 — «Портфель» (`Dashboard`, ~строка 1661) и «Интеграции» (~3408)
«Портфель» — главная сводка. Проверь и выровняй карточки/таблицы сводки под общий
язык (радиусы, отступы, мета-строки, точки типов). «Интеграции» — списки брокеров
и источников: те же правила.

### Волна 5 — «Импорт», «Отчёты», «Настройки», OCR-сводка
Если есть списки/карточки — те же правила. Если страница уже соответствует (нет
списков) — просто отметь в отчёте и не трогай.

## Правила выполнения

- Каждый заход: ровно одна вкладка (или пара мелких из одной волны), один коммит
  на английском в стиле истории (`feat:` / `fix:` / `refactor:`).
- НЕ меняй логику, API, расчёты, составление данных. Только вёрстка и CSS. Если
  кажется, что для внешнего вида нужен бэкенд-флаг — запиши как «открытый вопрос»
  в раздел ниже, не блокируйся и не трогай бэкенд.
- После каждой вкладки: `npx tsc -b`, `npm run build`, деплой статики
  (`npm run build && sudo cp -r dist/. /var/www/portfel/ && sudo chown -R
  www-data:www-data /var/www/portfel`), затем headless-скриншот 390×844 и 1280×800
  под временным тестовым аккаунтом (аккаунт `blasemobile@gmail.com` НЕ трогать и
  под ним не логиниться; временный аккаунт после проверки удалять). Скриншоты
  клади в `docs/redesign/` с именем `<вкладка>-mobile.png` / `<вкладка>-desktop.png`.
- Отмечай прогресс: в этом же файле ставь `[x]` напротив выполненной волны и
  дописывай одной строкой, что сделано и какой коммит. Файл сам — твой журнал.
